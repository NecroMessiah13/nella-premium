## 🧪 Тестирование

### Шаг 1: Проверить /checkout
```
http://localhost:3000/checkout
```
- Добавь товары в корзину
- Заполни форму
- Выбери "Карта / Яндекс.Касса"
- Нажми "Создать заказ"

### Шаг 2: Проверить создание платежа
Должен произойти redirect на `/api/payments/create?orderId=X`

Если всё в порядке:
- В БД должен появиться заказ с `paymentId`
- Должен быть redirect на тестовую форму оплаты YooKassa

### Шаг 3: Симулировать платёж
В тестовом режиме используй тестовые карты YooKassa:
- Номер: 4111111111111111 (успешно)
- CVC: 123
- Дата: 12/25

После успешного платежа:
- Webhook обновит заказ: `paymentStatus=PAID`, `status=PROCESSING`
- Redirect на `/payment/success`

## 📋 Что проверить в админке

http://localhost:3000/admin → Заказы
- Должны видны все заказы с платежами
- Статусы: NEW → PROCESSING (после платежа)
- Payment status: PENDING → PAID

## 🔄 Workflow при реальной интеграции

1. Обновить `.env` с реальными ключами YooKassa
2. Добавить webhook URL в админку YooKassa
3. Создать тестовый заказ
4. Проверить, что webhook приходит и обновляет заказ

## ❌ Возможные проблемы

| Проблема | Решение |
|----------|---------|
| Redirect не работает | Проверь YOOKASSA_SHOP_ID и YOOKASSA_SECRET_KEY в .env |
| Payment ID не сохраняется | Проверь логи контейнера: `docker logs nella-app` |
| Webhook не приходит | На локальной машине webhooks не работают (нужен ngrok) |
| 500 ошибка на /checkout | Проверь консоль браузера в DevTools |
